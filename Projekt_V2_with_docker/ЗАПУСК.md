# Инструкция по запуску

## 1. Установка зависимостей

Откройте командную строку и выполните:

```bash
cd c:\Dev\Projekt_V1\backend
py -3.12 -m venv .venv
.\.venv\Scripts\activate.bat
pip install -r requirements.txt
```

## 2. Настройка API ключа Яндекс

1. Перейдите на https://developer.tech.yandex.ru/
2. Получите API ключ для **JavaScript API и HTTP Геокодер**
3. Откройте файл `c:\Dev\Projekt_V1\backend\.env`
4. Вставьте ключ:

```
YANDEX_GEOCODER_API_KEY=ваш_ключ_здесь
```

## 3. Применение миграций

```bash
cd c:\Dev\Projekt_V1\backend
python manage.py migrate
python manage.py collectstatic --noinput
```

## 4. Создание суперпользователя (админ)

```bash
python manage.py createsuperuser
```

Введите:
- Email или телефон
- Пароль (не отображается при вводе)
- Повтор пароля

## 5.1 Запуск сервера локально

```bash
python manage.py runserver
```

## 5.2 Запуск сервера

В корне проекта Projekt_V2_docker использовать команду
При условии, что на диске C достаточно места (более 40 ГБ)
```bash
docker compose up --build
```

## 6. Открытие в браузере

- **Главная:** http://127.0.0.1:8000/
- **Админка:** http://127.0.0.1:8000/admin/

---

## 6.1 Для остановке сервера

```bash
ctrl + c
```

## Остановить контейнер
```bash
docker compose down
```

## Запустить в фоне (без логов в консоли)
```bash
docker compose up -d
```

## Смотреть логи в реальном времени
```bash
docker compose logs -f
```

## Полностью очистить проект (контейнеры + сеть + тома)
```bash
docker compose down --volumes --remove-orphans
```

## Весь проект собран в файле docker_data.vhdx, который был создан автоматически после запуска

## Как это работает

1. **Регистрация:** На главной странице нажмите "Регистрация", введите email/телефон и пароль
2. **Вход:** После регистрации вы автоматически войдёте в систему
3. **Оформление ДТП:**
   - Выберите "Европротокол"
   - Нажмите "Далее"
   - Пройдите шаги мастера
   - На шаге 6 нажмите "📍 Карта" для выбора места ДТП
4. **Карта:**
   - Кликните по карте для выбора места
   - Адрес определится автоматически
   - Нажмите "Подтвердить"
5. **Профиль:** Кнопка профиля вверху справа

## Решение проблем

### Ошибка "YANDEX_GEOCODER_API_KEY не настроен"

- Проверьте, что файл `.env` существует в папке `backend`
- Убедитесь, что ключ указан без кавычек и пробелов

### Карта не работает

- Проверьте API ключ в личном кабинете Яндекс
- Убедитесь, что ключ активен для JavaScript API

### Ошибки при запуске

```bash
# Очистите кэш Django
python manage.py shell -c "exit"

# Пересоздайте миграции
python manage.py makemigrations
python manage.py migrate
```


### Docker

## Если на диске C недостаточно места после команды docker compose up --build, можно перенести на другой диск
- Откройте Docker Desktop.
- Нажмите на иконку ⚙️ Settings (шестерёнка в правом верхнем углу).
- Перейдите в раздел Resources → Disk image location.
