# Инструкция по настройке ИИ-ассистента для ДТП

## 🚀 Быстрый старт

### 1. Настройка GigaChat

Для работы ИИ-ассистента необходим токен от GigaChat:

1. Получите credentials для GigaChat в личном кабинете разработчика
2. Откройте файл `backend/.env`
3. Замените значение `GIGA_AUTH` на ваш токен:

```env
GIGA_AUTH=ваш_токен_gigachat
```

### 2. Установка зависимостей

Все зависимости уже установлены. Если что-то пошло не так:

```bash
cd backend
pip install -r requirements.txt
```

### 3. Запуск сервера

```bash
cd backend
python manage.py runserver
```

Сервер запустится на **http://127.0.0.1:8000/**

### 4. Проверка работы API

Проверить доступность API можно по адресу:
- **http://127.0.0.1:8000/ai/api/health/**


## 💬 Как работает чат

1. Пользователь открывает чат-виджет на странице
2. Вводит вопрос по ДТП/ПДД/европротоколу
3. Frontend отправляет запрос на `/ai/api/chat/`
4. Backend:
   - Проверяет тему вопроса (должен быть про ДТП)
   - Ищет релевантный контекст в базе знаний
   - Отправляет запрос в GigaChat
   - Возвращает ответ пользователю

## 🔧 API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/ai/api/chat/` | Отправить сообщение в чат |
| GET | `/ai/api/health/` | Проверка доступности API |

### Пример запроса к чату

```json
POST /ai/api/chat/
Content-Type: application/json

{
  "message": "Что делать при ДТП?",
  "history": []
}
```

### Пример ответа

```json
{
  "response": "При ДТП необходимо...",
  "history": [["Что делать при ДТП?", "При ДТП необходимо..."]]
}
```

## ⚠️ Важные замечания

1. **Первый запуск** может занять несколько минут для загрузки модели эмбеддингов и построения базы знаний
2. **База знаний** хранится в `AI_agent/chroma_db/` и создаётся автоматически из файлов в `AI_agent/Docs_md/`
3. **Точность ответов** зависит от качества базы знаний и токена GigaChat

## 🐛 Возможные проблемы

### "ModuleNotFoundError: No module named 'langchain_huggingface'"
```bash
pip install -r requirements.txt
```

### "Ошибка: не настроен GigaChat"
Проверьте, что в файле `backend/.env` указан правильный токен:
```env
GIGA_AUTH=ваш_токен
```

### "База знаний не доступна"
Убедитесь, что папка `AI_agent/Docs_md/` существует и содержит markdown файлы с инструкциями.
