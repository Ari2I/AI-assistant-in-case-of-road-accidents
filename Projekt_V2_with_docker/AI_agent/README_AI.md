### 🚀 Инструкция по запуску бота

1.  **Первый запуск и загрузка базы**  
    Чтобы начать пользоваться ботом, необходимо один раз загрузить базу (запустить код). Первая загрузка будет долгой, но в последующие разы всё будет подгружаться моментально.

2.  **Точность ответов**  
    На данный момент ответы могут быть не совсем точными или выдавать неполную информацию.

3.  **Локальное тестирование**  
    Вы можете протестировать работу локально на своём компьютере. Если возникнут проблемы с библиотеками — напишите мне: [@Raiu21](https://t.me).

4.  **Установка библиотек**  
    Для скачивания всех необходимых зависимостей введите команду:
    ```bash
    pip install -r requirements.txt
    ```

5.  **Настройка GigaChat**  
    Для работы вам понадобится ваш код от GigaChat.  
    *   Скопируйте репозиторий к себе на устройство.
    *   В папке `AI-assistant` создайте файл `.env`.
    *   Внутри файла пропишите:  
        `GIGACHAT_CREDENTIALS=Ваш_токен_без_кавычек`
