# AI DTP Assistant

## 📂 Структура проекта
```
AI-assistant/
│
├── agent/
│   ├── core.py          # Основной pipeline (run_agent, rate_answer)
│   ├── planner.py       # Определение намерения пользователя (intent)
│   ├── generator.py     # Генерация ответа
│   └── filter.py        # Фильтрация сообщений не по теме ДТП
│
├── evaluation/
│   ├── self_check.py    # Самопроверка и улучшение ответа
│   └── critic.py        # Оценка ответа после пользовательского рейтинга
│
├── rag/
│   ├── retrieval.py     # Получение контекста из векторной базы
│   └── feedback_db.py   # Сохранение качественных пар Q&A
│
├── storage/
│   └── history.py       # Хранение истории диалогов (JSON)
│
├── chroma_db/           # Основная RAG-база (ChromaDB)
├── chroma_feedback/     # База дообучения на основе обратной связи
├── Docs_md/             # Документы для индексации в RAG
│
├── config.py            # Конфигурация (API-ключи, параметры)
├── main_AI.py           # Запуск бота через CLI
├── .env                 # Токен GigaChat (не коммитить в git!)
└── requirements.txt     # Зависимости проекта
```


## 💬 Как это работает

1. Пользователь вводит сообщение.
2. `run_agent()` выполняет следующий pipeline:
   - Проверяет тему через `filter.py` (только ДТП-тематика)
   - Получает релевантный контекст через RAG (`retrieval.py`)
   - Определяет намерение пользователя (`planner.py`)
   - Генерирует ответ (`generator.py`)
   - Проверяет и при необходимости улучшает ответ (`self_check.py`)
3. Возвращает объект вида:
```json
   { "answer": "...", "message_id": "..." }
```
4. Пользователь может поставить оценку от 0 до 5.
5. `rate_answer()`:
   - Сохраняет оценку в историю
   - Запускает критику ответа (`critic.py`)
   - При высокой оценке добавляет пару Q&A в базу дообучения (`chroma_feedback/`)
