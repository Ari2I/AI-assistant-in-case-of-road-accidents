# Цифровой ассистент при ДТП — Frontend шаблон

Минималистичный фронтенд‑шаблон мобильного web‑интерфейса для цифрового ассистента при ДТП. Проект рассчитан на дальнейшую интеграцию с backend (REST API, DevOps) и ML‑сервисами.

## Структура проекта

- `index.html` — разметка приложения и основные экраны.
- `styles.css` — стили (минимализм, mobile‑first).
- `app.js` — логика фронтенда, обработчики и точки интеграции с API.
- `png/` — PNG‑модели автомобилей для 2D‑схемы (например, `car1.png`, `car2.png`).

## Основные экраны

1. **Пошагово (wizard)**
   - Шаги оформления ДТП с верхней шкалой прогресса (Шаг 1 из 4).
   - Шаг 1: выбор типа происшествия:
     - «Серьёзное ДТП» — с пояснением, когда вызывается ГИБДД.
     - «Европротокол» — с простым объяснением условий применения.[web:61]
   - Кнопки «Назад» / «Далее», сохранение шага через API.
   - Блок загрузки фото/документов (file input, список выбранных файлов).

2. **Схема ДТП (diagram)**
   - 2D‑поле вида сверху с перетаскиваемыми элементами:
     - Машина A/B (привязка к PNG‑моделям через `data-image="png/carX.png"`).
     - Человек, самокат, велосипед.
     - «Место удара» (красный кружок), «Вмятина» (жёлтый кружок).
   - Сохранение схемы в JSON (тип + позиция + опционально картинка).

3. **Европротокол (euro)**
   - Упрощённый шаблон формы:
     - дата/время, место ДТП, свидетели;
     - данные авто A/B;
     - краткое описание обстоятельств.
   - Кнопка «Определить» рядом с полем «Место ДТП»:
     - использует `navigator.geolocation` и backend‑endpoint с Яндекс Geocoder.[web:79][web:89]

4. **Подсказки (help)**
   - Объяснения простым языком:
     - что такое европротокол;
     - порядок действий при его составлении;
     - как правильно фотографировать ДТП.[web:61]
   - Мини‑чат с ИИ:
     - ввод вопроса, вывод сообщений пользователя и ответа;
     - заглушка под `/api/chat`.

5. **Профиль (profile)**
   - Имя, email, телефон.
   - Смена пароля (новый + повтор).
   - Открывается поверх контента, закрывается кнопкой.

## Точки интеграции с backend (REST API)

Фронтенд уже содержит TODO‑комментарии и ожидаемые форматы данных.

### Черновик шага ДТП

```ts
POST /api/accident/draft
body: { step: number, type?: "serious" | "euro" }
```

Используется при нажатии «Далее» в модуле «Пошагово».

### Загрузка файлов (фото/документы)

```ts
POST /api/accident/files
body: FormData with files[]
response: { files: { id: string; url: string; name: string; size: number }[] }
```

Фронт сейчас только отображает выбранные файлы, отправка оставлена как TODO.

### Схема ДТП

```ts
POST /api/accident/diagram
body: {
  items: {
    type: "car" | "person" | "scooter" | "bike" | "impact" | "dent" | string;
    left: string; // "123px"
    top: string;  // "45px"
    image?: string | null; // например "png/car1.png"
  }[];
}
```

Собирается при нажатии «Сохранить схему».

### Европротокол

```ts
POST /api/accident/europrotocol
body: {
  date?: string;          // datetime-local
  place?: string;
  witnesses?: string;
  carA_owner?: string;
  carA_plate?: string;
  carB_owner?: string;
  carB_plate?: string;
  circumstances?: string;
}
```

Вызывается при нажатии «Сохранить данные европротокола».

### Профиль

```ts
GET  /api/profile
res: { name: string; email: string; phone: string; ... }

PUT  /api/profile
body: { name?: string; email?: string; phone?: string; password?: string }
```

Фронт проводит только базовую проверку совпадения паролей.

### Геолокация + Яндекс Geocoder

Фронтенд делает запрос:

```ts
GET /api/geocode/yandex?lat=<latitude>&lon=<longitude>
```

Ожидаемый ответ:

```json
{ "address": "Россия, Москва, Красная площадь, дом 1" }
```

Backend внутри вызывает Yandex Geocoder API:[web:89][web:94]

```text
https://geocode-maps.yandex.com/1.x/
  ?apikey=YOUR_API_KEY
  &geocode=<lon>,<lat>
  &kind=house
  &format=json
```

И вытаскивает `AddressLine` из ответа.

### Мини‑чат с ИИ

```ts
POST /api/chat
body: { message: string }
res: { reply: string }
```

Сейчас ответ имитируется через `setTimeout`, нужно заменить на реальный `fetch`.

## Быстрый запуск (для разработки)

1. Открыть проект в VS Code.
2. Установить расширение Live Server.
3. Запустить `index.html` через «Open with Live Server».
4. Открыть в браузере `http://127.0.0.1:5500/index.html` (порт может отличаться).

## Замечания по стилю и UX

- Стиль выдержан в минимализме: белый фон, простые карточки, чёткие подписи.
- Всё оптимизировано под мобильный экран (одна колонка, крупные кликабельные элементы).
- Сложные вещи (европротокол, порядок действий, фото) объясняются кратко и простым языком.

## Планируемые доработки

- Реальная многошаговость мастера (2–4 шаги с разным контентом).
- Интеграция с auth‑системой (вход/регистрация, отображение пользователя в шапке).
- Подключение реального Яндекс Maps JS API для отображения карты и маркера.
- Интеграция с ML‑сервисами (распознавание повреждений, анализ документов).
