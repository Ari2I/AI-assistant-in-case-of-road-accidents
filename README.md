# 🚗 Цифровой ассистент помощи при ДТП

**Комплексная экосистема для оформления ДТП, юридической поддержки и автоматизации взаимодействия со страховыми компаниями**

---

## 📌 О проекте

**Цифровой ассистент при ДТП** — это мобильное и web-решение, которое сопровождает водителя *на всех этапах происшествия*:
от первой минуты после аварии и фиксации повреждений до отправки документов в страховую компанию.

Проект объединяет:
✔ мобильное приложение (Android / iOS)
✔ web-интерфейс
✔ ML/AI-системы распознавания
✔ микросервисный backend
✔ геолокацию и карты
✔ DevOps-инфраструктуру и базы данных

Цель — **сократить ошибки при оформлении ДТП, ускорить сбор данных и автоматизировать юридические процессы.**

---

## 🧩 Основные модули платформы

### 📱 **Frontend (Web + Mobile)**

* Web-версия
* Адаптивный UI/UX (mobile-first)
* Пошаговый мастер оформления ДТП (wizard flow)
* Камера и галерея — съёмка места происшествия
* Геолокация и карта с фиксацией координат
* Проверка ОСАГО
* 2D-редактор схемы ДТП (вид сверху)
* Электронная подпись
* Чат-бот и push-уведомления

---

### 🖥️ **Backend (Микросервисы)**

Архитектура: **REST + GraphQL**, микросервисная структура.

Используемые технологии:

* Node.js, Python/Django, GoLang
* PostgreSQL, MongoDB
* Redis (кэш и очереди)

Безопасность:

* TLS/SSL шифрование
* 2FA
* HMAC-подписи для API
* Логирование, аудит, защита от повторных запросов

---

### 🤖 **AI / ML-компоненты**

* Распознавание повреждений авто по фото
* Классификация тяжести ДТП
* Проверка корректности заполнения документов
* Анализ текста для поиска ошибок
* Прогнозирование исхода страхового разбирательства
* Юридический чат-бот

---
